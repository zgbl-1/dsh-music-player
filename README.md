# dsh-music

给 DeepSeek Harness 用的本地音乐播放器插件：左侧栏入口、搜索、热歌榜、歌单收藏、播放模式、音质选择，切到其他面板音乐继续播放。

> **使用前请先读 [DISCLAIMER.md](./DISCLAIMER.md)。** 本插件不提供任何音乐内容，
> 仅做界面与接口聚合；版权、账号与合规风险由使用者自行承担。

## 功能

- 左侧栏「音乐」入口 + 独立主面板
- 搜索歌曲 / 网易云热歌榜
- 播放条：播放暂停、上一首下一首、进度拖动、音量
- 播放模式：列表循环 / 单曲循环 / 顺序播放
- 音质：自动（按可用档位从 320K 逐档降级）、320K / 192K / 128K
- 收藏歌单：多歌单、新建、删除、加入/移除歌曲，数据存在本机
- 网易云账号扫码登录（可选）：登录后 VIP 歌曲可播放完整音质
- 搜索历史、切面板继续播放、跟随封面取色的背景

## 安装（本地 bundle）

```bash
# 在 DeepSeek Harness 中执行：
#   plugin_manager install_bundle  D:\path\to\dsh-music-plugin
```

或在插件管理界面选择「从本地目录安装」，目标目录指向本文件夹。

安装后需要**重启 DSH**（Host 侧路由在启动时建立），客户端面板刷新页面即可看到。

## 数据位置

| 内容 | 路径 |
| --- | --- |
| 歌单 | `~/.dsh/dsh-music/library.json` |
| 网易云登录凭证 | `~/.dsh/dsh-music/account.json` |

删除这两个文件即可恢复初始状态。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 侧：`/api/dsh-music/*` 同源路由，代理搜索、播放地址、歌词、歌单、登录 |
| `client.js` | 客户端：侧栏图标 + 主面板播放器（React，无构建产物） |
| `cordis.patch.yml` | Loader 补丁 |
| `locale/*.json` | 插件管理器里显示的名称与说明 |
| `icon.svg` | 插件图标 |

## 技术说明

- 浏览器面板不能跨域请求音乐站点，所以由 Host 侧代理，页面只请求同源的 `/api/dsh-music/*`。
- 播放地址优先走第三方平台的公开播放地址接口，按码率逐档探测，全部失败才回退到
  兼容代理；登录账号后可用档位随之提高。
- 播放器状态放在模块级单例上，主面板卸载（切到别的面板）不会中断播放。
